5-STEP PROCESS
정기 위험성평가 작성 가이드
아래 5단계를 순서대로 진행합니다. 각 단계를 눌러 상세 안내를 확인하세요.
기본정보 › 조직도/실행계획 › 교육 › 참여서명 › 평가표 › 결과공유서명 › 승인

참여근로자 입력 및 계획서 작성

참여근로자 추가

  • 참여근로자 이름을 정확하게 입력하고 추가 버튼을 누릅니다.
  • 실행계획서 사전 작성 내용(평가계획일, 사전준비 내용 등)을 확인/수정합니다.

  • 교육 일자를 확인하고, 필요 시 사전 교육 사진 첨부를 통해 증빙을 등록합니다.

참여근로자 서명
QR코드 또는 주소를 통한 자필 서명

서명 진행 방법

  • QR 코드 보기 버튼을 눌러 근로자 스마트폰으로 스캔하게 합니다.
  • 근로자는 스마트폰 화면에서 본인 이름을 확인하고 자필 서명을 제출합니다.

5
평가표 작성
작업 공정별 JSA 위험성 평가
  • 16개 주요 공정을 순서대로 확인하며 유해/위험요인을 파악합니다.
  • 개선 전/후 위험성을 상/중/하로 판정하고 필요 시 사진을 첨부합니다.
6
결과공유서명
법적 요건 확인 및 결과 공유 전자서명
  • 위험성평가 후 결과 및 위험요인을 확인하는 체크리스트를 선택합니다.
  • 참여근로자에게 결과 공유 서명 주소를 전달하여 서명을 취합합니다.
7
승인
관리자 및 안전보건팀 최종 승인
  • 관리감독자가 확인 의견을 작성하고 제출을 진행합니다.
  • 이후 관리자(파트장 등)와 안전보건팀이 내용을 검토하고 최종 승인을 완료합니다.

조직도 · 실시계획서

조직도 작성

  • 위험성평가 실시체계 조직도를 확인합니다

    한 사람씩 입력 후 "추가" 클릭 → 하단부에 조직도 자동 생성
  • 1인 근무 매장이라도 입력 필수

실시계획서

  • 실시계획서를 확인하고 다른 직원에게도 안내합니다
  • TBM 시간을 활용하여 공유
  • 크게 보기 및 다운로드 가능

참여근로자 추가 후 반드시 임시 저장을 눌러주세요.
3
교육 / 근로자 참여
사전교육 및 전자서명 수집

① 전자서명 수집

🚨
2가지 서명 모두 필수
① 근로자 참여 서명   ② 평가결과 공유 서명
점장은 두 가지를 모두 발송하고, 직원도 2개 모두 서명해야 합니다.
  • 매장 점장이 기본 정보 입력 후 주소를 복사하여 카카오톡으로 직원에게 배포
  • 전자서명 또는 수기 작성 중 편한 방법으로 제출
  • 매장명은 자동 생성, 사번/이름 입력 후 서명일자는 반드시 출근한 날 입력
실제 화면
직원이 공유 링크에서 보는 근로자 참여 전자서명 화면

② 사전교육 기록

  • 교육 방식 선택: TBM 집합교육 게시공유 기타
  • TBM이 기본 적용됩니다
  • 좌측 하부 사전교육 완료 확인 클릭
  • 교육일자는 실질적으로 교육한 날짜 기록
⚠️
교육일자 주의 — 평가일 이전에 교육을 실시해야 합니다.
예) 평가일 2026.10.30 → 교육일자 2026.10.22~10.27 사이

③ 사진 및 서명록 첨부

  • 참여 확인 사진과 결과 공유 사진은 누락 없이 첨부
  • 수기 작성 시: 좌측 "문서·자료"에서 서명록 출력 → 자필 서명 후 사진 첨부
  • 현장 사진 및 매장 고유 위험정보 함께 확인
💬
직원에게 위험요소가 없는지, 평소 위험하다고 생각하는 것이 없는지 의견을 청취 후 자필 서명하여 서명록을 첨부합니다.

평가표 작성
JSA 기반 위험요인 기록

작성 전 준수사항

  • 관리감독자는 준수사항을 확인 후 전자서명 실시
  • 전자서명을 완료한 후 "평가표 작성" 클릭하여 평가 진행
⚠️
전자서명을 진행하지 않으면 다음으로 넘어가지 않습니다.
실제 화면
관리감독자 평가 준수사항 확인 및 전자서명 화면

평가 기법: JSA + 상·중·하

상 — 사망·중대재해 가능성, 즉시 개선
중 — 부상·질병 가능성, 개선 계획 수립
하 — 경미한 위험, 현재 안전조치 적정

16개 작업공정 순서

  • 정기평가표는 16개 작업공정 순서로 구성되어 있습니다 (예: 출근·근무복 착용·보호구 점검 → 매장 오픈 준비 → … 순)
  • 화면 상단의 공정 순서 스트립(칩)을 클릭하면 해당 공정으로 바로 이동합니다
  • 각 공정 헤더에 "OO개 항목"이 표시되므로, 공정별로 빠짐없이 확인 후 다음 공정으로 이동

작성 요령

  • 적용/미적용 선택 — 미해당 시 "미해당" 클릭
  • 위험성 "하"인 경우 다음 항목으로 자동 이동
  • 위험성 "상·중"인 경우:
    — 개선전/후 사진 첨부 (가능 시)
    — 개선대책/실행방안 작성 (기작성분 활용 가능)
    — 개선예정일 / 개선후 위험성 / 완료일 작성
  • 16개 공정에 걸쳐 빠짐없이 위험요소를 확인하여 작성
  • 막연하게 쓰지 말고 실제 작업 기준으로 작성
실제 화면
PC 화면 기준 JSA 위험성평가표 — 작업순서·유해위험요인·개선대책 입력
💾
평가 중간/실시 후 임시 저장 필수! 다른 항목으로 넘어가기 전 반드시 눌러주세요.
📖 개선이 어려운 경우 안내 ▼
  • 개선이 안 될 경우 개선후 위험성은 개선전과 동일하게 두면 됩니다
  • 개선 예정일과 완료일은 다른 날로 지정하는 것이 좋습니다
  • 개선 비용 발생 시 하단 비고란에 금액 기재
    예) 사다리 교체 _53,000원
  • "하" 상태라도 위험성이 없다는 것이 아닙니다 — 미약한 위험이라도 표시하여 직원이 숙지할 수 있도록 관리

FAQ
자주 묻는 질문
총 10개 질문에 대한 답변입니다.
Q1QR이 열리지 않아요▼
인터넷 연결을 확인하고 다시 스캔해 주세요. 그래도 안 되면 PC에서 직접 주소를 입력하거나 관리자에게 문의하세요.
Q2모바일 작성이 어려워요▼
위험성평가는 내용이 방대하므로 가급적 PC(컴퓨터)로 작성해 주세요. PC와 모바일 모두 같은 주소를 사용합니다.
Q3해당 항목이 없어요▼
"작업 단계 추가하기" 클릭 후 추가해 주세요. 작업공정마다 추가 기재가 가능합니다.
Q4다음으로 넘어가지 않아요▼
필수 입력/등록 사항을 확인해 주세요 (서명록, 일자 등). 전자서명 미진행 시 다음 단계로 넘어가지 않습니다. 다른 항목으로 넘어가기 전 임시저장을 반드시 눌러주세요.
Q5재접속 했는데 기존 작성 내용이 없어요▼
작성 중 임시저장을 하지 않으면 내용이 유실될 수 있습니다. 항목을 변경하기 전에 반드시 임시저장을 눌러주세요.
Q6위험성이 중/상인데 개선하지 못했어요▼
개선후 위험성을 그대로 중/상으로 유지해 주세요. 위험성이 있음을 표시하는 것이 중요합니다.
Q7내용이 우리 매장과 맞지 않아요▼
기작성된 내용을 수정·추가하여 작성해 주세요. 모든 항목은 변경 가능합니다.
Q8개선예정일을 모르겠어요▼
개선이 어려워 못하는 항목은 날짜를 비워 놓으세요. 개선 예정일과 완료일은 다른 날로 지정하는 것이 좋습니다.
Q9항목이 너무 많아요▼
다이소 전체에서 재해가 발생한 항목은 필수 조건이라 양해 부탁드립니다. 미해당 항목은 "미해당"을 클릭하면 빠르게 넘어갈 수 있습니다.
Q10평가표에 해당하는 항목이 없어요▼
작업공정마다 있는 "작업 단계 추가하기"에서 추가 기재해 주세요.
